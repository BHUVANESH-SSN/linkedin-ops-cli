        🧠 What I Learned & Implemented

        🔹 1️⃣ Agentic AI Architecture
        Designed an agent loop that:

        1. Understands user intent

        2. Plans actions

        3. Calls tools when needed

        4. Evaluates results

        5. Returns structured output

        Moving from static responses → to autonomous decision-making.

        🔹 2️⃣ RAG (Retrieval-Augmented Generation)
        Learned how to:

        1. Retrieve relevant documents

        2. Inject contextual knowledge into prompts

        3. Reduce hallucinations

        4. Build scalable, knowledge-driven AI systems

        RAG shifts LLMs from “trained knowledge only” to “dynamic real-time knowledge.”

        🔹 3️⃣ Function Calling

        Implemented tool integration so the agent can:

        1. Fetch external data

        2. Process structured inputs

        3. Execute programmatic actions

        This transforms AI from conversational to operational.

        🔹 4️⃣ Fine-Tuning Concepts

        Understood how fine-tuning:

        1. Improves domain specialization

        2. Reduces prompt complexity

        3. Enhances consistency

        Optimizes model behavior for specific business use cases

        🔹 5️⃣ Efficiency & Optimization

        Focused on:

        1. Token efficiency

        2. Latency reduction

        3. Cost-aware prompt engineering

        4. Structured outputs for reliability

        🚀 Project: Website Summarizer using LangChain, Groq & RAG Architecture

        I built an AI-powered Website Summarizer that not only generates concise summaries from live URLs, but also implements Retrieval-Augmented Generation (RAG) concepts for scalable and accurate LLM workflows.

        This project helped me move beyond basic LLM usage into production-style AI pipelines.

        🔧 Tech Stack & Architecture

        1. LangChain – Prompt templates, document loaders, summarization chains

        2. Groq (ChatGroq API) – High-speed inference using LLaMA-3.1-8B

        3. RAG Pipeline – Retrieval + generation for context-aware summaries

        4. Embeddings – Text vectorization for document chunking and retrieval

        5. Vector Search – Similarity search over embedded content

        6. Streamlit – Interactive web interface

        7. Python – Core orchestration

        ✨ Key Features

        ✔️ Extracts and chunks website content
        ✔️ Generates embeddings for semantic understanding
        ✔️ Retrieves relevant chunks using vector similarity
        ✔️ Feeds retrieved context into LLM (RAG flow)
        ✔️ Multiple summarization strategies (stuff, map_reduce, refine)
        ✔️ Adjustable summary length
        ✔️ Robust error handling & version-safe imports

        🧠 What I Learned

        1. Designing RAG pipelines from scratch

        2. How embeddings enable semantic retrieval

        3. Chunking strategies and Vector indexing

        4.Prompt Engineering for summarization & context control

        5. LangChain internals and evolving API structure

        6. Building LLM-backed applications with real UI UX.

        Github Repo:
        https://lnkd.in/gRQFn7M6

        I sincerely thank to Pratham Uday Chandratre Bhaiya for his guidance and mentorship. Under his supervision, I explored core LLM concepts, RAG, and gained hands-on experience with embeddings and real-world GenAI workflows.
